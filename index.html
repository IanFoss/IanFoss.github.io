Professional Self-Assessment

Throughout the Computer Science program at Southern New Hampshire University, I have developed the skills needed to design, build, evaluate, and improve software systems. My coursework and ePortfolio helped me showcase my strengths in software engineering, database design, secure coding, algorithms, communication, and technical problem solving. The capstone gave me the opportunity to return to an earlier Android application, evaluate its weaknesses, and improve it through planned enhancements. One of the most important lessons I learned is that successful software must be more than functional. It should also be readable, maintainable, secure, and useful to its intended users. Courses such as CS 320 helped me understand the importance of testing and quality assurance, focusing on creating software using Test-Driven Development. Courses like CS 405 strengthened my understanding of secure coding, input validation, authentication, and defense in depth by giving me practical experience identifying and fixing some of the most important security vulnerabilities such as buffer overflows and SQL injection. These experiences shaped my professional goal of becoming a software engineer who creates reliable and secure applications. The program also helped me improve my ability to communicate technical ideas. Through written documentation, diagrams, code reviews, and project narratives, I practiced explaining how systems work and why certain design decisions are made. Courses like CS-250 and CS-255 provided a thorough introduction to industry specific documentation that uses the Unified Modeling Language, such as UML class diagrams, sequence diagrams, and other behavioral and structural diagrams. These documents are important to accurately convey technical information in a way that is easy to understand. Collaboration was also an important part of my growth. Even when projects were completed individually, I learned to write code and documentation in a way that would support future teamwork. Readable code, comments, consistent structure, and separation of concerns all make it easier for others to understand and contribute to a project. My capstone reflects this by improving the structure of the Android application and organizing functionality through activities, entities, DAOs, repositories, and supporting utility classes. My understanding of data structures and algorithms also grew throughout the program. I learned how searching, sorting, filtering, and complexity analysis affect application performance and usability. In my capstone, I applied these ideas by adding search, sort, and filter features to the inventory list. These features allow users to locate items by name, view items alphabetically or by quantity, and identify low-stock or out-of-stock items more efficiently. Courses like CS-300 allowed me to take a deep dive into how these algorithms work, how to analyze time and space complexity, and how to create data structures from scratch. Software engineering and database development became major areas of focus for me. In CS 465, I gained experience with a MEAN stack application using Express, Angular, MongoDB, and API endpoints. This greatly sharpened my web development skills, gaining practice in working with NoSQL document-based databases, backend routing concepts, API creation, and component-based user interface design. In the end, I created a fully functional full-stack application using modern technology. In my capstone, I applied similar layered-design ideas in an Android environment using Room for local data storage. I improved the database by adding stronger validation, new schema fields, password hashing and salting, and a Room migration to support schema changes without relying on destructive migration. The artifacts in my ePortfolio fit together as a progression of improvements to one Android inventory management application originally created in CS 360. Enhancement One modernized the app from Java to Kotlin and improved account validation. Enhancement Two added search, sort, and filter functionality to improve how users interact with inventory data. Enhancement Three improved the Room database implementation by strengthening password security, data integrity, validation, and migration handling. Together, these enhancements demonstrate my ability to analyze an existing application, identify weaknesses, and improve it across multiple areas of computer science. They show my skills in software design, algorithms and data structures, database development, secure coding, collaboration, and technical communication. Completing this ePortfolio has helped me better understand my strengths and professional goals. As I move forward, I want to continue developing applications that are practical, maintainable, secure, and valuable to users.
